# Central Contalger

Arquivos prontos para publicar no GitHub Pages.

## Como publicar
1. Envie `index.html` e `logo-contalger.png` para a raiz do repositório `Central-Contalger`.
2. No GitHub, abra **Settings > Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)**.
5. Clique em **Save**.

O site ficará no padrão:
https://mauroruan2004-code.github.io/Central-Contalger/
